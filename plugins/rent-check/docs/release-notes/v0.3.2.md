# rent-check v0.3.2

## Highlights
- rent-check now ships from the hov-stack repository. Existing installs pick up the move on their next plugin update.
- The skill now bundles its fact engine, a stdlib-only Python script that counts load cost, finds dead path references and lists claims to check against the repo.
- The rubric and evidence notes grew with the engine and cover the checks it now runs.

## Details

This is the first rent-check release from `plugins/rent-check/` in
[StartupBros-com/hov-stack](https://github.com/StartupBros-com/hov-stack). The
marketplace entry switches from the old `StartupBros-com/rent-check` repository to
this directory, and that repository will be archived with a README that points here.

It also carries the one feature change that merged after v0.3.1 and never
released: StartupBros-com/rent-check#14 added `skills/rent-check/bin/rent-check.py`
(subcommands `inventory`, `refs`, `emphasis`, `expiring`, `claims`, `delta`,
`memory`, `ledger-write` and `ledger-resolve`), its fixture suite
`bin/rent-check.test.py`, and the matching `SKILL.md`, `RUBRIC.md` and
`EVIDENCE.md` text. The fixture suite now runs in hov-stack CI on every change to
the plugin.

Nothing else in the skill changed. The release-pipeline commits on the old
repository (StartupBros-com/rent-check#15) do not ship in the plugin.
