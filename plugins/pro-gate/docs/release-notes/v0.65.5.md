# pro-gate v0.65.5

## Highlights

- A pull request whose diff holds terminal escape bytes can be reviewed again with gh 2.103 or later.

## Upgrade

The marketplace plugin update brings the new skill, and the hourly auto-update timer or the
next `/pro-gate` run installs the 0.65.5 runtime. Nothing to change by hand.

## Details

- **Escape bytes in the compare diff.** gh 2.103 and later refuse to print an API response
  that holds terminal escape sequences unless given `--allow-escape-sequences`, and they
  refuse even when the output goes to a file. Evidence preparation fetches the PR's compare
  diff that way, so a PR that adds or deletes a captured-TTY fixture, or any file with ANSI
  colour codes, failed with "PR patch fetch failed; no review submitted". Such a PR could
  get no review, and a PR that needs the gate could not merge. Preparation now passes the
  flag on that one fetch when `gh api --help` lists it. An older gh keeps the plain call,
  since it never refused. The prepared patch holds the diff byte for byte, escape bytes
  included. The other gh reads ask for JSON, which escapes those bytes, so they were never
  affected ([#460](https://github.com/StartupBros-com/hov-stack/issues/460)).
