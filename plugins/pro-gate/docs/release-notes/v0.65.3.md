# pro-gate v0.65.3

## Highlights

- pro-gate now ships from the hov-stack repository, and the runtime installs and updates from there.
- A recovery check that saw only a placeholder conversation link now reports the review as absent instead of inconclusive.

## Upgrade

The marketplace plugin update brings the new skill, and the next `/pro-gate` run installs the
0.65.3 runtime from hov-stack. Hosts with the hourly auto-update timer log failed downloads
until that run, because the 0.65.2 updater looks for the release in the old repository. Run
`/pro-gate` once after the plugin updates and the timer follows hov-stack from then on.

## Details

This is the first pro-gate release from `plugins/pro-gate/` in
[StartupBros-com/hov-stack](https://github.com/StartupBros-com/hov-stack). The marketplace
entry switches from the old `StartupBros-com/pro-gate` repository to this directory. That
repository will be archived with a README that points here, and it keeps every release up to
v0.65.2.

- **Release location.** The installer, the auto-updater and the doctor's newest-release check
  now use `pro-gate--v<version>` releases in hov-stack. The skill and the reviewer agent fetch
  the installer from that tag. The runtime archive and its checksum are unchanged in shape.
- **Recovery.** When a placeholder conversation link failed the conversation-ID check, the
  same process kept it as a recovery handle, so a later empty scan stayed inconclusive while a
  fresh process reported absent. The link is now checked before it is kept, and a valid
  earlier handle is preserved.
- **Contract pins.** The review-decision generator's check now covers the contract ID and
  version pins as well as the digests, so a drift in either is caught before release. Runtime
  decisions are unchanged.

The plugin's suites now run in hov-stack CI from `tests/ci.sh` on every change to the plugin.
