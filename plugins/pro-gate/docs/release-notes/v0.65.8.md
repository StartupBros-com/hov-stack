# pro-gate v0.65.8

## Highlights

- Decision lookup no longer fully validates thousands of unrelated saved input bindings before returning an action.

## Upgrade

Update the marketplace plugin and install the matching 0.65.8 runtime. The opt-in auto-updater follows the promoted plugin version. Existing review records and configuration need no migration.

## Details

- **Faster lookup with a large review history.** The decision query previously ran the full binding validator for every saved input, then discarded inputs for other repositories, pull requests or revisions. It now checks those target fields in bounded batches before invoking the existing validator. A local synthetic public-CLI test with 2,213 unrelated bindings took about 34 seconds before this change and less than one second afterward, returning the same complete decision envelope. These timings are fixture measurements, not live model-review timings.
- **The same acceptance checks.** The prefilter supplies candidates, never approval. Possible matches, uncertain input bytes and exceptional files still reach the existing reader. Failed or incomplete batches fall back to the original list. Canonical records, supported contracts, proof and artifact validation, ordering, review policy and guarded dispatch are unchanged. No persistent index or new dependency is introduced.
