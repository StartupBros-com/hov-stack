# pro-gate v0.65.4

## Highlights

- A review that ChatGPT stops with "Selected model is at capacity" is now released promptly instead of being held as still generating.

## Upgrade

The marketplace plugin update brings the new skill, and the hourly auto-update timer or the
next `/pro-gate` run installs the 0.65.4 runtime. Nothing to change by hand.

## Details

- **At-capacity banner.** ChatGPT can end a Pro generation with "Selected model is at
  capacity. Please try a different model." and a Retry button, then write nothing more to the
  conversation. The salvage classifier didn't list that line among its terminal
  infrastructure errors, so it read the conversation as still generating. The engine kept the
  reservation until the generation ceiling: about 14 hours on the case that found it. Salvage
  now treats the line like the other terminal errors: recovery is released, and the charged
  round is kept. Matching is unchanged. It needs the exact line in a structured error element
  with a Retry button nearby, after the run's marker. An assistant answer that only quotes the
  phrase still counts as still generating
  ([#430](https://github.com/StartupBros-com/hov-stack/pull/430)).
