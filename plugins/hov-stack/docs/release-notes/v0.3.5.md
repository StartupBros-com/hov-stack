# hov-stack v0.3.5

## Highlights

- New slash skill /hov-stack:learn-taste turns the design corrections from your past sessions into rules, shows them first, then writes them where the next agent reads them.
- In repos set up with design-rails it writes into design/DESIGN.md. Ask it to read every project and it labels rules from other projects instead of applying them.

## Details

**Get this version.** Run `claude plugin update hov-stack@hov`, then restart Claude Code.
If the hov plugins update themselves, it arrives on its own.

v0.3.4 was built but never published: this release replaced it before it went out.
Its changes reach members here.

Changes since v0.3.3:

- **learn-taste, new.** This is Emil Kowalski's `learn-taste` skill from
  `emilkowalski/skills` at `64eb3de`, MIT, vendored unchanged. Run it as
  `/hov-stack:learn-taste`. The model never starts it on its own.
  - It reads your previous Claude Code session in the repo and finds the design
    corrections you made there: things you said, changes you undid, and edits you made to
    the agent's files by hand.
  - It proposes each one as a rule with its reason, and writes only after you say so.
  - When a rule already existed and the agent broke it anyway, it rewrites the rule
    stricter or adds a check, instead of repeating it.
  - It is not installed for Codex, because it reads Claude Code transcripts.
- **data-source-clis.** The per-host configuration list drops its
  `with-gemini-sandbox` line. The launcher fetched a Gemini key from the
  maintainer's own Bitwarden record and stopped with an error anywhere else.
  The maintainer stopped using Gemini CLI, so the launcher is gone from the
  harness, along with its test and its link entry.

The harness checkout also drops pi's Antigravity image extension and its entry
in pi's startup cockpit. Neither is part of this plugin.

What was measured for learn-taste, from `docs/vets/2026-11-16-learn-taste-harness-vet.md`.
The fixture used synthetic sessions, one model and 3 runs per arm, so these are small numbers.

- learn-taste scored a median 7 of 8 planted corrections handled correctly. The same
  request without it scored 5. Two other tools, claude-reflect and nvie's self-review,
  scored 6, which the fixture counts as a tie.
- Every learn-taste run proposed before writing, invented no rules, and never followed a
  planted prompt injection.

Known limit: running `design-rails propose --out=design` again overwrites
`design/DESIGN.md` and drops the rules learn-taste wrote there (hov-stack#685).
