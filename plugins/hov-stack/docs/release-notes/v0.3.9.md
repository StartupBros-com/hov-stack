# hov-stack v0.3.9

## Highlights

- The verify-phases skill is removed. The pack's hooks, a repository's own check script and the built-in /verify already cover what it did.

## Details

**Get this version.** Run `claude plugin update hov-stack@hov`, then restart Claude Code.
If the hov plugins update themselves, it arrives on its own.

Changes since v0.3.8:

- **verify-phases removed.** The skill ran format, lint, typecheck and optionally tests in
  order, stopping at the first failure. It was renamed from `verify` in v0.3.8 and is now gone.
  - It overlapped what already runs on its own:
    - the auto-format hook formats after each edit;
    - the `verify-on-stop` hook runs a repository's `.claude/verify.sh` or its typecheck
      script when a turn ends;
    - secret scanning belongs in CI.
  - It also worked against its name:
    - its format and lint steps rewrote files;
    - its Python path reformatted the whole repository;
    - it checked only one half of a mixed Python and Node repository;
    - it ran package-manager scripts that the harness's worktree command checks refuse.
  - Use instead:
    - a repository's `.claude/verify.sh` for its own checks;
    - Claude Code's built-in `/verify` to build and run the app and watch a change work.
  - Nothing replaces `/hov-stack:verify-phases` or `/verify-phases`.
  - A checkout of hov-stack keeps a dead `~/.claude/skills/verify-phases` link until
    `scripts/skills-localize.sh apply` runs, because that is the step that removes broken skill
    links. Deleting the link by hand works too.
