# hov-stack v0.3.8

## Highlights

- The verification-phases skill is renamed from verify to verify-phases, so it no longer shares a name with the built-in /verify command.

## Details

**Get this version.** Run `claude plugin update hov-stack@hov`, then restart Claude Code.
If the hov plugins update themselves, it arrives on its own.

Changes since v0.3.7:

- **verify-phases, renamed from verify.** The skill that runs format, lint and typecheck in
  order and stops at the first failure was named `verify`, the same name as Claude Code's
  built-in `/verify` command. With the pack's skills linked into a checkout's skills directory,
  `/verify` could reach either one depending on which Claude Code resolved first. Its behaviour
  is unchanged; only the name moves.
  - Plugin members: run `/hov-stack:verify-phases` where you ran `/hov-stack:verify`.
  - Checkouts of hov-stack: run `/verify-phases` where you ran `/verify`. After `./setup --update`,
    `/verify` reaches only the built-in.
  - There is no alias for the old name: an alias would bring back the collision the rename
    removes.
