# hov-stack v0.3.7

## Highlights

- /hov-setup now installs gh 2.104.0, uv 0.13.8 and jsm 0.3.48, each checked against a checksum taken from its maker's release.

## Details

**Get this version.** Run `claude plugin update hov-stack@hov`, then restart Claude Code.
If the hov plugins update themselves, it arrives on its own.

Changes since v0.3.6:

- **hov-setup.** The pinned releases that /hov-setup installs move up: gh from 2.103.3 to 2.104.0,
  uv from 0.13.7 to 0.13.8, and jsm from 0.3.46 to 0.3.48, on Linux (x86-64 and ARM) and macOS
  (Apple silicon and Intel). The script still checks each download's sha256 before installing it
  and runs `--version` on the new copy before replacing the old one. The gh and uv checksums were
  also confirmed against the makers' signed build attestations; jsm publishes none, so its
  checksums come from its download server alone. Running /hov-setup again moves the copies it
  installed to these versions. A copy that has changed since then, such as a jsm that updated
  itself, or one that is already newer, is left alone.

Checkouts of hov-stack got this table on their next `./setup --update`; this release brings it to
members who use the plugin.
