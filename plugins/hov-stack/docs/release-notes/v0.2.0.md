# hov-stack v0.2.0

## Highlights

- /hov-setup is now one guided conversation: it asks what you want Claude to help with, then offers only what fits, in plain words.
- It offers every plugin and program hov-stack works with, from other publishers too, and gets each one working before moving on to the next.
- It can turn on auto-update so the hov plugins fetch new versions by themselves, and `./setup --update` updates everything it installed.

## Details

Every change in this release is in one skill, `/hov-setup`, the second stage of setup.

**Get this version.** Auto-update is off for the hov plugins until you turn it on, so this
one update is by hand: run `claude plugin update hov-stack@hov`, then restart Claude Code.
Then type `/hov-setup` and say yes when it asks whether the hov plugins should update
themselves. After that, new versions arrive on their own.

**One guided pass.** `/hov-setup` first asks what you want Claude to help with: everyday
work, working on code, or tuning your own Claude setup. It then shows a short card for each
thing that fits, saying what it does, what it costs and what you will have to do. It installs
only what you pick, one at a time, and checks that each one works before the next. Logins and
password prompts stay with you; it tells you exactly where to type them.

**Everything hov-stack works with.** Besides the optional hov plugins, it now offers plugins
from Every, OpenAI, Anthropic and Matt Van Horn, and programs such as GitHub's `gh`,
`ast-grep`, `synthetic-panel` and `cass`. A program it installs is downloaded at one
version hov-stack checked and compared with that version's checksum first; on a mismatch
nothing is installed. It installs into `~/.local/bin` and never asks for your password.

**Updates.**

- When the hov plugins' auto-update is off, `/hov-setup` asks once before turning it on in
  your `settings.json`, and keeps a copy of the old file. A setting someone switched off
  stays off. Adding another publisher's plugin turns on auto-update for that publisher's list
  too.
- `./setup --update`, run in your hov-stack folder, updates the folder and then everything
  `/hov-setup` installed. It replaces a program only when the copy on disk is still the one it
  put there, and only after the new version passes its checksum and starts. A copy you
  installed another way, such as with Homebrew or apt, is left to that.

**sign-it.** The sign-it check now matches sign-it 0.6.2, which ships its own packages, so a
current copy needs no extra install step.
