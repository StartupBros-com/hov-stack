# hov-stack v0.1.1

## Highlights

- The hov-stack skill pack is out: /plugin install hov-stack@hov adds the stack's 45 skills as one plugin.
- It covers interface and design review, writing and editing, research, verification and agent workflows.
- Cloning hov-stack and running ./setup links these skills directly, so a clone does not need this plugin.

## Details

This is the first release of the skill pack, `plugins/hov-stack/` in
[StartupBros-com/hov-stack](https://github.com/StartupBros-com/hov-stack), and
the first core release. Core releases are tagged `hov-stack--v<version>`. The
pack's version was staged at 0.1.0 when the stack joined the repository and
was never released; the release chain tags only a version that changes, so
the first release is 0.1.1.

The 45 skills:

- **Interface and design:** `animate`, `apple-design`, `better-accessibility`,
  `better-colors`, `better-layout`, `better-typography`, `better-ui`, `break`,
  `emil-design-eng`, `explain-interface`, `find-animation-opportunities`,
  `improve-animations`, `interface-review`, `measure`, `pick-ui-library`,
  `prototype`, `review-animations`, `show-me`, `ux-writing`.
- **Writing:** `better-writing`, `brand-voice-builder`, `code-slop`, `eli5`,
  `kill-ai-slop`, `writing-for-agents`.
- **Research and data:** `data-source-clis`, `deep-research`,
  `firecrawl-research-index`, `google-safe-browsing`, `posthog-cli`,
  `slack-admin`, `youtube-transcript`, `cass-rerank-local`.
- **Verification and review:** `create-verification-skill`,
  `maintain-verification-skill`, `verify`, `verify-review`,
  `thermo-nuclear-code-quality-review`.
- **Agent workflow:** `agent-swarm`, `bro`, `codex-consult`, `goal-brief`,
  `scaffold-agents-md`, `hov-setup`, `papercut`.

Not in the pack:

- `memory-mine` and `review-adversarial-first` call the stack's own scripts,
  which a plugin install does not have, so they live in `skills-stack/` and
  only `./setup` links them.

The pack also carries a `papercut` skill, which the papercut plugin ships as
well. `./setup` links neither copy and installs the papercut plugin instead.

Every skill is MIT-licensed under the repository's `LICENSE` and carries a copy
of it, except those listed in `NOTICE.md`, which carry their upstream licence
and an `UPSTREAM.md` recording the source and what this copy changed.
