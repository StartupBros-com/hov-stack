# hov-stack v0.3.0

## Highlights

- The papercut skill now comes only from the papercut plugin, so having both plugins no longer gives you two papercut skills.
- If you use papercut and installed only hov-stack, run `/plugin install papercut@hov` to keep it. `./setup` already installs it.

## Details

**Get this version.** Run `claude plugin update hov-stack@hov`, then restart Claude Code.
If the hov plugins update themselves, it arrives on its own.

**papercut.** The hov-stack pack carried a copy of the `papercut` skill, and the papercut
plugin ships one too. With both plugins installed, Claude saw two skills of one name. The
pack's copy is gone. The papercut plugin's copy stays: it runs papercut through the
plugin's own launcher and comes with the hook that records failed tool calls, while the
pack's copy needed a `papercut` command already on your PATH.

`./setup` installs the papercut plugin and never linked the pack's copy, so a setup made
with `./setup` loses nothing. Run `/plugin install papercut@hov` only if you installed the
hov-stack plugin by itself and want to keep papercut.
