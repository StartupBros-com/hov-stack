# hov-stack v0.3.10

## Highlights

- The firecrawl-research-index skill now says Firecrawl's research search category still returns ordinary web pages, not papers, so agents keep paper questions on the paper tools.
- The data-source-clis skill now covers firecrawl-cli's optional Firecrawl Local tier: free local page fetches, and the page instead of an error when the budget refuses a summary.

## Details

**Get this version.** Run `claude plugin update hov-stack@hov`, then restart Claude Code.
If the hov plugins update themselves, it arrives on its own.

Changes since v0.3.9:

- **firecrawl-research-index: the research category is a web filter.** Firecrawl's docs
  announced that `firecrawl-cli search --categories research` would search the paper index
  and return paper records under `data.research` from 2026-11-16. It has not: the vendor
  CLI's own help (1.30.0) says the category "is NOT the paper index", and a live search on
  2026-11-20 returned web pages under `data.web`. The skill now says so. Its advice is
  unchanged: for paper-finding, use the paper tools it lists. `firecrawl-cli` reads either
  bucket, so nothing breaks if Firecrawl makes the move later.
- **data-source-clis: the Firecrawl Local tier.** `firecrawl-cli` comes with a hov-stack
  checkout's `./setup`. When the pinned `firecrawl-local` build is installed beside it:
  - `fetch` of a page to markdown, html, rawHtml or links (`--full` or `--format`) runs on
    your machine first, for no credits, with a `local:` note;
  - a private or loopback address is refused rather than sent to the cloud;
  - a plain `fetch` (the cloud summary) that the session budget or the account floor refuses
    now returns the page's markdown, exit 0, with a `local: summary not run` note naming
    the refusal and how to lift it;
  - `--cloud` skips the tier when a local page looks mangled.

  Firecrawl publishes no `firecrawl-local` release yet, so the tier is a build-from-source
  extra and `/hov-setup` does not offer it. Without it, `firecrawl-cli` behaves as before.
