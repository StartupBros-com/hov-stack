# hov-stack v0.3.1

## Highlights

- youtube-transcript reads only the video you asked for, so a second download in the same folder can no longer turn another video's captions into your transcript.
- posthog-cli runs data queries through the posthog-api wrapper, so answers come from the project you named, not whichever project your login has active.
- Seven skills stop contradicting themselves, among them animate on modal timing, verify on repos with no format script, and agent-swarm on batching its skeptics.

## Details

**Get this version.** Run `claude plugin update hov-stack@hov`, then restart Claude Code.
If the hov plugins update themselves, it arrives on its own.

Changes since v0.3.0:

- **youtube-transcript.** The caption converter read whichever `*.json3` file in the
  output folder came first. It now reads only `<name>.<lang>.json3` for the video it
  downloaded, uses the plain `en` track when yt-dlp writes both `en` and `en-orig`,
  refuses when several tracks match and none is plain `en`, and writes `<name>.txt`
  into the output folder. `UPSTREAM.md` records the local change.
- **posthog-cli.** Data queries go through `posthog-api PROJECT`. A bare
  `posthog-cli api` with only `POSTHOG_CLI_PROJECT_ID` set answers from the login's
  active project. `UPSTREAM.md` records the change.
- **interface-review.** Triggers are exempt from the 15-finding cap, as the skill's
  own rule that a cap may never hide a blocker requires.
- **animate, emil-design-eng.** The one-line duration summary and the review table now
  carry the exception their own tables give modals and drawers (up to 500ms).
- **find-animation-opportunities.** The "`transform` and `opacity` only" rule names
  animate's two exceptions, `clip-path` and `height` for accordions, which its own
  hold-to-confirm and accordion recipes use. `UPSTREAM.md` lists the change.
- **verify.** With no format script, the format step is skipped, as the skill's FORMAT
  table and rules say; it no longer falls back to `prettier --write .`.
- **agent-swarm.** Skeptics verify per batch of related findings, matching the skill's
  fan-out rules.
- **codex-consult.** The description and intro say Codex runs your selected model
  instead of naming one, since the skill never pins a model.
- **data-source-clis.** Notes that `firecrawl-cli raw -- <verb> --help` for a vendor
  work verb is local help and costs nothing.
