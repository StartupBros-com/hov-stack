# hov-stack v0.3.11

## Highlights

- The agent-swarm skill now tells the agents it starts that plain shell commands and simple chains pass the worktree check, so only a refused shape goes in a script file.
- The code-slop skill no longer links to a technical-debt skill that hov-stack does not include.

## Details

**Get this version.** Run `claude plugin update hov-stack@hov`, then restart Claude Code.
If the hov plugins update themselves, it arrives on its own.

Changes since v0.3.10:

- **agent-swarm: plain commands in the dispatch preamble.** The preamble pasted into every
  dispatched agent's prompt used to send any multi-step or loop work to a script file. It
  now says plain, separate commands pass, `&&`, `;` and pipe chains included. Only a shape
  the worktree check refuses goes in a script file, run as `bash <file>`, never `bash -c`.
  The preamble also names example refused shapes (a loop variable, `$( )` in an argument,
  or an argument that is a builtin name like `eval` or `source`), so the agents it starts
  know them without any CLAUDE.md. (#922; the examples are new in this release.)
- **code-slop: no pointers to a skill that is not here.** The skill's description and
  intro, and two of its rules, named or linked `technical-debt`, a sibling skill in the
  upstream pack that hov-stack never included. They now say "metrics" without naming it,
  and the dead links are gone. The review rules themselves are unchanged.
- **Licences.** The plugin's own licence and those of its 13 first-party skills now name
  House of Vibe and its site beside StartupBros LLC (#909). Third-party skills keep their
  upstream licences.
