# hov-stack v0.3.3

## Highlights

- hov-setup no longer turns product-video away on pnpm 11. It updates a 0.2.0 copy to 0.2.1 first, which installs on pnpm 11 and passes its setup check.

## Details

**Get this version.** Run `claude plugin update hov-stack@hov`, then restart Claude Code.
If the hov plugins update themselves, it arrives on its own.

Changes since v0.3.2:

- **hov-setup, product-video.** The walkthrough no longer tells members that
  product-video can't finish installing on pnpm 11, and no longer holds back
  its recommendation there. When the installed copy is 0.2.0, it runs
  `claude plugin update product-video@hov` first and reads the new install
  folder: on 0.2.0 the install stops on pnpm 11 with `ERR_PNPM_IGNORED_BUILDS`,
  and the setup check fails on its own sample clip whatever the pnpm version.
  product-video 0.2.1 fixes both. If an install still stops, the walkthrough
  offers to skip it, and it still never changes pnpm's settings or approves a
  package's build script.

product-video 0.2.1 was installed the way the walkthrough installs it, on one
Linux host with pnpm 11 and Node 24, and its setup check passed. The new
walkthrough text has not been run through a hov-setup session.
