# token-eater v0.1.3

## Highlights

- token-eater now ships from the hov-stack repository. Existing installs pick up the move on their next plugin update.
- The footer on pull requests token-eater opens now links to its new home in hov-stack.
- The Windows scheduled-task examples now use a placeholder user folder you replace with your own.

## Details

This is the first token-eater release from `plugins/token-eater/` in
[StartupBros-com/hov-stack](https://github.com/StartupBros-com/hov-stack). The
marketplace entry switches from the old `StartupBros-com/token-eater`
repository to this directory. That repository will be archived with a README
that points here.

Changes since v0.1.2:

- **Pull request footer.** The provenance line `run-session.sh` writes under
  each draft PR links to `plugins/token-eater` in hov-stack.
- **Internal sharing, same behaviour.** The PR safety banner, and the change
  and scope classification the claude, codex and grok adapters share, each run
  through one shared routine with the same text, outputs and exit codes. Each
  has its own regression test.
- **Docs.** The install lines name the hov-stack marketplace, the Windows
  `schtasks` examples use `C:\Users\user\…`, and the July ideation refresh is
  included under `docs/`.

The offline suite now runs in hov-stack CI from `tests/ci.sh` on every change
to the plugin. The old repository's release-train scripts and their tests were
not carried over; hov-stack's release workflow replaces them.
