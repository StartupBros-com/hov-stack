# sign-it v0.6.3

## Highlights

- When sign-it can't confirm its folder is private, the receipt and privacy note now say "a private folder on this computer" instead of promising only your login can open it.

## Details

Changes since v0.6.2:

- **Owner-only wording follows `doctor`.** When `doctor.protection` is `unverified`,
  the opener already left out the owner-only promise, but the Step 5 receipt's storage
  line and the privacy statement still made it. All three now say "in a private folder
  on this computer" in that case. The spec's status line and privacy section say the
  same. The quoted opener and receipt blocks are unchanged, so the tests that pin them
  still apply.
