# sign-it v0.4.0

## Highlights

- Refuses drafts: DRAFT, Proposed Revision, For Discussion, For Review, Not for signature, Sample, Specimen, Template, Void and similar markers in a header, footer, watermark or short banner stop `sign` and `fill`; the agent quotes the phrase and asks whether the text is final before anything is stamped.
- `sign-it finalize offer.docx --remove "Proposed Revision for Discussion"` strips exactly the named text from the Word file's headers, footers, body and watermarks into `offer-final.docx`; it never picks which words to remove, and writes nothing if the text is absent.
- The whole draft handling is a plain conversation for the user: "sign that" on a draft gets one question; "this is final" gets a finalized, converted, signed and filled copy; no flags to know.
- Block values (Printed Name, Title, Email) are asked once in plain words and reused.
- 164-check suite; both draft paths proven with headless Claude Code sessions.
