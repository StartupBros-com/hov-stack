# sign-it v0.6.2

## Highlights

- sign-it works right after you install it: its Node packages now ship inside the plugin, so there is no `pnpm install` step, before or after an update.

## Details

Changes since v0.6.1:

- **Bundled runtime packages.** A plugin install copies the plugin and runs
  nothing, so on v0.6.1 `doctor` stopped with `ERR_MODULE_NOT_FOUND` until the
  user ran `pnpm install` by hand. The four runtime packages (pdf-lib, pngjs,
  jpeg-js, fflate) now ship as bundles in `skills/sign-it/scripts/vendor/`, built
  from the lockfile by `tools/vendor.mjs`; `scripts/vendor/NOTICE` carries the
  license of every bundled package.
- **CI.** `tests/ci.sh` fails when a committed bundle differs from a rebuild of
  the lockfile, and the suite now copies the skill without `node_modules` and
  runs `doctor`, `setup`, `sign` and `finalize` from that copy.
- **Docs.** The README no longer asks for `pnpm install`; its Tests section says
  how to rebuild the bundles.

An install that hand-ran `pnpm install` keeps working; the `node_modules` it made
is no longer used.
