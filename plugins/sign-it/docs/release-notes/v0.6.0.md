# sign-it v0.6.0

## Highlights

- sign-it now starts only when you type `/sign-it` at the start of a message. Claude never starts it on its own, so no document gets signed in your name unless you asked for it, and the skill adds nothing to a session's context until you call it.
- Inside a `/sign-it` conversation, follow-ups such as "sign that", "the other one too" and "change my title" still work as before.
- If you used to say "sign this PDF" and let the agent pick it up, type `/sign-it` with the document instead. `/sign-it setup` changes your signature or details.
- Every message that used to tell you to "say 'sign that'" now says "type /sign-it". No change to how documents are found, stamped, filled or sealed; 216-check suite.
