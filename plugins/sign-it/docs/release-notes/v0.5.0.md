# sign-it v0.5.0

## Highlights

- First run is a conversation: say "sign that" with nothing set up and the agent asks one multiple-choice question at a time, in plain words, and never shows a flag, a path or a file format.
- Draw your signature once, on this computer (a page opens; press Save and it is stored, nothing to download) or on your phone through a short link that works for ten minutes and once, or hand over any photo or picture of your signature and the background is cut away.
- You see your signature rendered on a sample line before it is ever used, and can redraw; the previous one is kept until you approve the new one, and "undo" brings it back.
- Name, title, company, email and date style are asked once, stored privately on this computer only, and reused; a form that needs one you skipped asks for exactly that one.
- Security reviewed: single-use 128-bit links, images checked for declared size before decoding, no token ever printed by doctor, owner-only files.
- 221-check suite; the four first-run paths proven with headless Claude Code sessions.
