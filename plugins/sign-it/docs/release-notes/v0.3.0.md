# sign-it v0.3.0

## Highlights

- `sign-it fill <pdf> --set "Printed Name=…" --set "Title=…" --set "Email=…" --near "YOUR COMPANY"` completes the signature block: labeled blanks and form fields are matched by label, the column under a party header is chosen with `--near`, blanks that already carry text are refused, and an unmatched or ambiguous label writes nothing.
- `sign-it fields <pdf>` lists every labeled blank and text field with its page, column and ink, for discovery before filling.
- Chains with `sign` in either order through `--out`; the first real use converted a two-party Word agreement, signed it, dated it and filled the block end to end.
- 149-check suite, including the running-header trap: a party name that also sits in the page header no longer steers `--near` to the wrong column.
