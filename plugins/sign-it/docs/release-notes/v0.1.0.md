# sign-it v0.1.0

## Highlights

- Say "sign that": the skill finds the signature line, stamps your stored signature and today's date, renders a preview, and hands back `<file>-signed.pdf`.
- Three slot sources in confidence order: AcroForm signature fields, text-layer blanks after a label, and tesseract OCR for scanned pages (flagged approximate).
- Fails closed: no configured signature, no slot, or an ambiguous slot stops with the candidates listed; nothing is ever guessed or fabricated, and the input is never overwritten.
- Optional PAdES seal from a locally generated PKCS#12 via pyhanko.
- 87-check test suite on synthetic fixtures, including rotated pages and AcroForm edge cases; MIT-only dependency tree (pdf-lib).
