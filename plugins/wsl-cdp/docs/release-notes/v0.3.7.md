# wsl-cdp v0.3.7

## Highlights

- wsl-cdp now ships from the hov-stack repository. Existing plugin installs pick up the move on their next plugin update.
- The one-line installer now downloads from hov-stack. Re-run the new install line from the README to stay current.
- Release tags now look like wsl-cdp--v0.3.7, and the installer accepts one as WSL_CDP_REF to pin a release.

## Details

This is the first wsl-cdp release from `plugins/wsl-cdp/` in
[StartupBros-com/hov-stack](https://github.com/StartupBros-com/hov-stack). The
marketplace entry switches from the old `StartupBros-com/wsl-cdp` repository to
this directory. That repository will be archived with a README that points
here.

The old one-liner keeps working, but it installs the archived repository's last
version. The new line is:

```bash
curl -fsSL "https://raw.githubusercontent.com/StartupBros-com/hov-stack/main/plugins/wsl-cdp/install.sh?$(date +%s)" | bash
```

The installer still resolves the ref to one commit and downloads all four
scripts pinned to it. Nothing else changed for users since v0.3.6: one commit
moved a shared login-store setup into the test helper. A new offline test runs
the installer with `curl` stubbed and checks every URL it requests.
