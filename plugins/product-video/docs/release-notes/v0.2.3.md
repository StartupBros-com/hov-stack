# product-video v0.2.3

## Highlights

- source-map-js is now 1.2.2 and fast-uri 3.1.9, past the advisories against the versions the renderer installed before.
- Development tools move past the brace-expansion and minimatch advisories, so the plugin has no open Dependabot alerts.
- Rendering and the checks run as they did in v0.2.2; only dependency versions change.

## Details

Changes since v0.2.2:

- **Runtime dependencies.** source-map-js 1.2.1 to 1.2.2 (GHSA-68fv-2mgg-jv7q,
  high) through postcss 8.5.28 to 8.5.33, and fast-uri 3.1.7 to 3.1.9
  (GHSA-w74x-v6f9-j3xg, GHSA-hrr3-gc8f-f4qj). Both are pulled in by
  Remotion's bundler, so they reach your machine with the renderer. nanoid
  moves from 3.3.18 to 3.3.20 alongside postcss.
- **Development dependencies.** brace-expansion 1.1.18 and 5.0.9 to 1.1.22 and
  5.0.13 (GHSA-q2hr-2g5m-vwhr). minimatch 10.2.6 to 11.0.8 (GHSA-g3hv-75wg-m249)
  through typescript-eslint 8.69.0 to 8.73.0, whose range in `package.json`
  is now `^8.73.0` so a fresh install cannot fall back to minimatch 10.
  minimatch 3.1.5 stays: eslint 9 pins it and the advisory does not cover 3.x.
- **No code changes.** Every change is in `package.json` and `pnpm-lock.yaml`.

The offline suite passed at this release's commit on one Linux host with pnpm 11
and Node 24. A real Remotion render was not tried for this release.
