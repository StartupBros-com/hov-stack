# product-video v0.2.2

## Highlights

- zod is now 4.6.7, past the memory-exhaustion advisory that covers zod up to 4.6.5.
- A scenario step with an unknown key now reports its other problems too, such as a prohibited selector, instead of the unknown key alone.

## Details

Changes since v0.2.1:

- **zod 4.4.3 to 4.6.7.** Advisory GHSA-mrhx-c7xc-m3w5 (CVE-2023-54404)
  covers zod up to 4.6.5: validating a very large array can collect one issue
  per bad element until the process runs out of memory. product-video's
  schemas read scenario, telemetry and manifest files from your own machine,
  so the exposure was a malformed local file, not input from the network.
  4.6.7 is the version Remotion 4.0.543 already installs, and its published
  package differs from 4.6.6 only in its version number, so the plugin now
  carries one copy of zod instead of two. That also clears the zod 4.4.3
  versus 4.6.7 mismatch `remotion versions` reported in v0.2.1.
- **Validation output.** Since zod 4.5.0 an unknown key in a strict object no
  longer stops that object's own checks. A click step with the selector
  `password` and an extra key used to fail with only the unknown-key issue; it
  now fails with that issue and the prohibited-control issue.
- **Tests.** The click and move test that pinned the old one-issue result now
  checks both cases: with an allowed selector an unknown key is the only
  issue, and with a prohibited selector both issues are reported, unknown key
  first.
