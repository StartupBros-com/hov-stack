# product-video v0.2.0

## Highlights

- Tours can now have spoken narration: each caption cue is synthesized and placed at its own start time, so it stays in sync.
- The on-screen pointer now moves like a hand, along curved paths and sampled at the video's frame rate.
- Capture no longer letterboxes on displays that cannot back the requested scale, and product-video now ships from hov-stack.

## Details

This is the first product-video release from `plugins/product-video/` in
[StartupBros-com/hov-stack](https://github.com/StartupBros-com/hov-stack). The
marketplace entry switches from the old `StartupBros-com/product-video`
repository to this directory. That repository will be archived with a README
that points here. Existing installs pick up the move on their next plugin
update.

Changes since v0.1.0:

- **Narration.** The docs used to forbid external text-to-speech, which left
  every tour silent unless you recorded audio by hand. `narrated:voice` now
  speaks each caption cue separately and places it at that cue's start time, so
  a moved cue cannot drift out of sync.
- **Pointer motion.** The pointer path is sampled at the video's frame rate
  instead of about 15 Hz, and it travels along curves instead of straight
  tweens.
- **Capture scale.** A capture scale above the display's native pixel ratio
  letterboxed the recording. Capture now handles a display that cannot back
  the requested scale. This was found on the first smoke test against an app
  other than the one the plugin was built on.
- **Internal sharing, same behaviour.** Bounded command execution, manifest
  loading, the subprocess policy, duration tolerance, selector refinement and
  atomic file publication each run through one shared routine, with tests that
  hold the old acceptance boundaries.

The offline suite (tests, type check, lint and format) now runs in hov-stack CI
from `tests/ci.sh` on every change to the plugin.
