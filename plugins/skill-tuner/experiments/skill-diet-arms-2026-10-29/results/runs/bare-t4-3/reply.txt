I wrote `./biggest.sh` and ran it once. It prints the three largest files under `./data`, largest first, as size in bytes followed by path:

```
12000 ./data/b.txt
8000 ./data/d.dat
5000 ./data/a.bin
```

The script uses `find ./data -type f -printf '%s %p\n' | sort -rn | head -n 3`. `-printf` is a GNU `find` option, so it won't work with BSD/macOS `find`.
