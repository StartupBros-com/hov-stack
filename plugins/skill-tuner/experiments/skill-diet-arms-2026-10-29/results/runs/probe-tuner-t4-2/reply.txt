I wrote `./biggest.sh` and ran it. It prints the three largest files under `./data`, largest first, as size in bytes followed by path:

```
12000 ./data/b.txt
8000 ./data/d.dat
5000 ./data/a.bin
```

The script is `find ./data -type f -printf '%s %p\n' | sort -rn | head -n 3`. It uses GNU `find`, so it won't work as written on macOS or BSD.
