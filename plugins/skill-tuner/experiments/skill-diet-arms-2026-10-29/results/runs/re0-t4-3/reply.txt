I created `./biggest.sh` and ran it once. It printed:

```
12000 ./data/b.txt
8000 ./data/d.dat
5000 ./data/a.bin
```

The script uses `find` to list every file under `./data` with its size in bytes, sorts those sizes from largest to smallest, and keeps the top three. Filenames with spaces work, because the size is the first field on each line.
