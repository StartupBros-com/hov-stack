# skill-tuner v0.9.1

Fixes for the five findings an independent code review confirmed on v0.9.0 (issue #55). v0.9.0 was staged but never published; this is the first release carrying the `claude plugin eval` reader and the `neutral_ids` routing option.

## Highlights

- `compare --plugin-eval` names the compared files and arms in its text report instead of printing the literal words "candidate vs baseline".
- The plugin-eval reader refuses a document whose `aggregates.casesTotal` disagrees with its case list, and a case with an errored run in the requested arm, unless that case is passed to `--exclude`.
- Two spellings of the same result file are recognised as the same run, so the same-arm refusal cannot be bypassed with a relative path or a symlink.
- The routing-parity `neutral_ids` option is covered by tests that assert the router never sees a real id and that the manifest records the alias map.
- `/skill-tuner:tune` step 5 points at the neutral-id battery config, matching the doctrine's routing-parity caveat.
- The compare subcommand's source flags live in one table shared by the mutual-exclusion check and the compare log.
