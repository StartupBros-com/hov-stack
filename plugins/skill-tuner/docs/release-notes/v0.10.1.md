# skill-tuner v0.10.1

The first release cut from hov-stack. The per-repo release train in this repository was frozen on 2026-10-24 (hov-stack restructure plan, U20), and the plugin ships from `plugins/skill-tuner/` in the hov-stack repository from this version on; `/plugin install skill-tuner@hov` is unchanged. Unlike the other migration notes, this one cannot say "nothing else changed": v0.10.0 (2026-09-23) left eleven pull requests unreleased (#59 to #66, #71, #72, #74).

## Highlights

- **Doctrine v3.2** (#72). Two body edits gated together against a fresh `claude-sonnet-5-5` baseline over the same 15 documents: 38 vs 34 confirmed findings, 95% CI [−0.56, +1.09], landed as *not worse* at δ = 1.0, never as better. A new `[craft]` bullet, "Rule, not incident" (write the behaviour a lesson asks for as one positive rule and leave the dated incident to the commit message), and the environment-as-source-of-truth sentences moved into their own bullet. Both keep `[craft]`; each has a falsifier in `FALSIFIERS.md`, and the isolated effect of either edit is unmeasured.
- **The description fires on shortening briefs** (#72). "shortening" joined the trigger list at routing parity (48/48 under both descriptions, ids hidden) after a live routing probe fired the skill 3/3 against the old description's 1/3 on a slimming brief. #74 measured one more word, "improving", with skill-creator installed as a live competitor, and refused it: with skill-creator present the skill fired on 0 of 3 improve briefs under either description, and without it the current description already fired 2 of 3 (`reports/trigger-improving-summary.md`).
- **Endtask reports keep the resolved model** (#65). The in-memory rows dropped `model_resolved`, so `manifest.resolved_models` was always empty. The field is retained, with regressions for deduplicated identities, unknown identities and budget-halted runs.
- **Announce workflow pin rolled to 41bb6f8** (#66), the marketplace commit whose announce workflow matched main at the time; the root workflow set in hov-stack supersedes the per-repo copy after the fold-in.
- **Six de-duplication refactors** (#59 to #64): shared probe output instructions with byte-parity fixtures, an in-process CLI test helper, the routing skill test fixture, paired-case exclusion matching, the CLI passing-verdict policy, and portfolio source-error bookkeeping. Behaviour unchanged; the unit suite grew from 248 tests at v0.10.0 to 284.
- **Harness-vet of nicobailon/skill-diet** (#71): verdict SKIP, three follow-ups (#68, #69 landed through #72; #70 open), and the vet's arm fixture under `experiments/skill-diet-arms-2026-10-29/`.
