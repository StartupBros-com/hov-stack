# hov v0.1.4

## Highlights

- OMP receives mail notices while working, instead of waiting for another user turn.
- A three-second timer can wake an idle OMP agent for new mail, respecting plan mode and user pauses and never repeating an old notice.
- While the mailbox is quiet, a check costs a file stat instead of a ~40 ms process.

## Details

The OMP extension keeps its before-turn check and adds a tool-result check plus a managed timer.
Timer notices use OMP's non-interrupting aside delivery. Only counts and sender tokens enter context;
message bodies still require an explicit inbox read. No user prompt, abort, permission change, or
session takeover is involved. One in-flight poll prevents overlap, and results from an old session
are discarded after switching or shutdown.

Checks are gated on the mailbox file. `hov notify --json` now names it (`db`), and an empty poll
writes nothing, so the extension stats that file and its WAL and runs `hov notify` only when one
changed since the session's last clean poll, plus every 20th unchanged check as a backstop. An
ungated three-second poll measured about 40 ms of Python each time, roughly 1% of a core per OMP
session even while idle. The saving holds while the host's mailbox is quiet: any write, including
the `last_seen` stamp each Claude Code hook event records, opens the gate for one poll, so on a host
with busy Claude Code sessions most checks still poll. A switched-to session polls at once, and a
`hov` that names no `db` (older than 0.1.4) is polled on every check, as before.

Copy the updated `omp/hov-mail.ts` into `~/.omp/agent/extensions/` and restart OMP to load it.
OMP 18.18.9's `/reload-plugins` does not reload extension code. OMP itself suppresses automatic
turns in plan mode and after an Esc pause. Delivery does not guarantee that a model obeys a peer.

Regression tests use simulated OMP callbacks/timers and the real mailbox subprocess. They cover
mid-turn mail, busy and idle dispatch, deduplication, overlapping polls, failure recovery, session
switches, shutdown, subagent exclusion, and the change gate with its backstop and version skew;
they are not a live-model test.

Fixes [the OMP delivery issue](https://github.com/StartupBros-com/hov-stack/issues/542).
