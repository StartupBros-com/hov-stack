# hov v0.1.11

## Highlights

- hov ls now shows which repository and branch each session is working on. Add --repo NAME to list only the sessions in one repository and message just those.

## Details

Picking who to message by session name reached unrelated sessions in 25 of 48 sampled fan-outs on one host, because Claude Code's own session listing shows no directory. Each session row from `hov ls --json` now carries:

- `dir`: the newest working directory the session's transcript recorded, else the directory it was launched in. `dir_from` says which. Claude Code's session listing and the process both keep the launch directory, so a session that moved into a worktree after launch still showed its main checkout there.
- `repo`: the GitHub owner/name of the checkout's `origin`, else the main checkout's folder name.
- `branch`, `worktree` (the checkout's top folder) and `checkout` (the main checkout).

When the transcript's directory no longer exists, as when a worktree is removed after its merge, the row says `dir_from: "gone"` and names no repository. A finished session is not shown as working on its main checkout.

`--repo` (and a `repo` argument on the MCP `ls` tool) keeps only the sessions in one repository. It matches the whole owner/name, the name or the checkout folder name, in any case, so `hov-stack` does not match `hov-stack-extra`. With `--repo`, mailboxes and links are left out. The text form ends each session line with `at=repo:branch`.

The transcript format belongs to Claude Code and is not documented. hov reads only the last 256 KB of the transcript, or 4 MB when one long entry hides the newest directory, and treats anything it cannot read as no transcript. The `git` and transcript reads run outside the mailbox write lock (the lesson of hov-stack#767).

Three new tests cover:

- a session that moved into a worktree, with its newest directory behind a line longer than the first read;
- a session that entered a worktree and came back, which is reported on its main checkout;
- a session whose worktree is gone;
- a session with no transcript;
- a directory outside any repository;
- `--repo` matching whole names only;
- the MCP tool's `repo` argument.

The change is hov-stack#840.
