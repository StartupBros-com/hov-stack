# memory-dream v0.4.1

## Highlights

- memory-dream now ships from the hov-stack repository. Existing installs pick up the move on their next plugin update.
- Triage no longer hides proposals that failed or were skipped, and a later successful apply now outranks an older rejection.
- Archiving keeps entries you chose to retain, even when they share text with an entry being archived.

## Details

This is the first memory-dream release from `plugins/memory-dream/` in
[StartupBros-com/hov-stack](https://github.com/StartupBros-com/hov-stack). The
marketplace entry switches from the old `StartupBros-com/memory-dream`
repository to this directory. That repository will be archived with a README
that points here. The standalone CLI still installs from a clone, now from
`plugins/memory-dream` in hov-stack.

Changes since v0.4.0:

- **Triage.** Only proposals whose apply manifest records them as applied are
  suppressed. Failed, skipped, unapproved and unmatched proposals come back. A
  successful later apply supersedes older rejections for the same path, and
  deferral-streak updates hold a lock across the whole read and write, so an
  older run can no longer roll back a newer one.
- **Build.** New index entries follow the store's established append style when
  that style is clear. A split or compress survivor whose description changed
  but whose routing hook did not now raises a warning. New split extracts no
  longer inherit the source note's session id or write time. A draft cluster
  missing from the chosen plan is reported as such, not as source drift.
- **Archive.** Preview and apply remove whole entry blocks, one per manifest
  entry, so retained entries that share lines with archived ones survive.
- **Verify.** A finding that passes a later quote recheck drops its stale
  failure flag.
- **Doctor.** Inaccessible Windows profiles no longer abort the probe or
  preview-home discovery.
- **Docs.** `commands/dream.md` explains where the deferral-streak file lives
  and that it is never pruned automatically.
- **Internal sharing, same behaviour.** Wikilink resolution for the inbound
  index and atomic JSON writing for eval artifacts each run through one shared
  routine. Each has its own regression test.

CI now runs the suite on the hov-stack runner's Python only. The old
repository also tested macOS, Windows and Python 3.10.
