# harness-vet v0.3.4

## Highlights

- A behavioral vet now reports cost from three runs per arm instead of passing or failing a small text change on it, replacing the cold-cache procedure added in 0.3.3.

## Details

0.3.3 asked every vet that measures cost to set a per-arm token count that
marks a run as starting on a cold prompt cache, and to declare a rule for
replacing such runs before reading any result. No vet had used that
procedure, and it added steps to every cost-measured vet to work around
noise that three runs cannot overcome anyway.

It is now one sentence: cost from three runs per arm cannot pass or fail a
change of a few lines, so report it, and make it a pass condition only with
enough runs to beat its noise. The measurement behind it stays: in the
2026-11-14 pstack re-vet, runs that started on a cold cache wrote 9,814 to
13,508 more cache-creation tokens than the warm median of the same arm and
task, and two such runs in one three-run cell set its median.

The other 0.3.3 rules stay: write the adoption rule down before the runs,
give each countermetric a declared tolerance, and judge the unit that ran.
