# papercut v0.1.23

## Highlights

- The route-guard test-noise rules now fire. They were keyed on a placeholder label that no guard writes, so test-suite records from hov-stack's route guard were ranked as real friction.
- papercut's logger labels git-guard and codex-quota-guard failures with the names those guards really use, so they join the guards' own records instead of splitting off under a placeholder.

## Details

papercut was first packaged from a private harness, and the packaging step
replaced every guard name with a placeholder (`a-vcs-guard`, `a-route-guard`,
`another-guard`). Those guards now ship publicly in hov-stack's
`hooks/PreToolUse/`, and they write their real names into papercut's store.
Code that matched the placeholders matched nothing:

- `papercut list` and `rollup` drop test-fixture records before ranking. The
  two route-guard rules looked for `guard_blocked:a-route-guard`; the guard
  writes `guard_blocked:canonical-worktree-route-guard`. They now match.
- The failure logger's fallback labels for git-guard and codex-quota-guard
  text now read `guard_blocked:git-guard` and
  `guard_blocked:codex-quota-guard`.

Comments, the skill and the tests use the real names too. The private-name
check stops banning those two guard names, because both are public. A new
hov-stack test fails if the packaged copy ever names a guard label that no
shipped guard writes.

Nothing changes for an install without hov-stack's guards: the affected rules
only ever match records those guards write.
