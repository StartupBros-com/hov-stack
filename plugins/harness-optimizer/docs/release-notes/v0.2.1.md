# Harness Optimizer v0.2.1

## Highlights

- Harness Optimizer now ships from the hov-stack repository. Existing installs pick up the move on their next plugin update.
- The README's install line and release section now point at hov-stack. The skill itself works as it did in v0.2.0.

## Details

This is the first Harness Optimizer release from `plugins/harness-optimizer/` in
[StartupBros-com/hov-stack](https://github.com/StartupBros-com/hov-stack). The
marketplace entry switches from the old `StartupBros-com/harness-optimizer`
repository to this directory. That repository will be archived with a README
that points here.

The only change on the old repository after v0.2.0 updated its own release
workflow, which never shipped in the plugin. One entry in the skill's
integrations reference used to link the author's private configuration
repository. It now names those components without a link or paths.

The offline suite now runs in hov-stack CI from `tests/ci.sh` on every change
to the plugin. One test was not carried over: `tests/test_release_gate.py`. It
read the old repository's release workflow, and hov-stack's release gate covers
the same checks.
